# 🛒 Amazon E-Commerce Clone (8x Assessment)

A high-performance, responsive Amazon E-Commerce web application built with **Next.js 16**, **React 19**, **Tailwind CSS v4**, **Lucide Icons**, and **Canvas Confetti**.

![Amazon Clone](https://images.unsplash.com/photo-1526170375885-4d8ecf77b99f?auto=format&fit=crop&w=1200&q=80)

## ✨ Key Features

- **🛍️ Amazon Navigation Header**: Sticky navbar with brand logo, delivery location selector, category-filtered search bar with live query filtering, account menu, returns/orders link, and dynamic cart badge.
- **⚡ Category Sub-Header & Carousel**: Dynamic promotional hero banners with automated carousel sliding, today's deals toggle, and quick category filtering drawers.
- **📱 Responsive Product Catalog**: Grid layout of products across Electronics, Fashion, Home & Kitchen, Gaming, Books, and Beauty with star ratings, prime indicators, sale badges, and pricing.
- **🔍 Multi-Attribute Filtering & Sorting**: Filter by Category, Price Range, Minimum Rating, Prime Eligibility, and Today's Deals; sort by Price (Low/High), Rating, and Newest.
- **🔍 Product Quick View Modal**: Interactive modal displaying high-res gallery, thumbnail selector, color & size variant selectors, key feature bullet points, and full spec matrix.
- **🛒 Slide-Over Cart Drawer**: Real-time cart drawer with quantity adjustments, item removal, subtotal calculation, and a dynamic **Free Shipping Meter** ("Add $X more for FREE Shipping!").
- **🎉 Interactive Checkout & Confetti**: Multi-step secure checkout process (Shipping Address, Payment Method, Order Review) with celebratory **Canvas Confetti** animation upon order confirmation.
- **💾 Persistent State Management**: React Context (`CartContext`) with local storage persistence for cart items, wishlist items, toast notifications, and filter states.

## 🛠️ Technology Stack

- **Framework**: [Next.js 16 (App Router)](https://nextjs.org/)
- **UI Library**: [React 19](https://react.dev/)
- **Styling**: [Tailwind CSS v4](https://tailwindcss.com/)
- **Icons**: [Lucide React](https://lucide.dev/)
- **Celebration Effects**: [Canvas Confetti](https://github.com/catdad/canvas-confetti)
- **Language**: TypeScript

## 🚀 Getting Started

1. **Clone the repository:**
   ```bash
   git clone https://github.com/rajneeshverma1/8x-Assessment-.git
   cd 8x-Assessment-
   ```

2. **Install dependencies:**
   ```bash
   npm install
   ```

3. **Run the development server:**
   ```bash
   npm run dev
   ```

4. **Build for production:**
   ```bash
   npm run build
   ```
